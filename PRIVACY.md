# Privacy Policy

Last updated: 2026-06-21

b3ehive is an open-source collection of local agent workflow skills and a Codex
plugin package. The project itself does not operate a hosted service, collect
analytics, sell data, or transmit user data to a b3ehive-controlled backend.

## What b3ehive Contains

b3ehive provides reusable `SKILL.md` files, references, scripts, templates, and
plugin metadata for Codex and other agent platforms. When installed, these files
run inside the user's chosen agent environment.

## Data Processing

b3ehive may cause the user's agent environment to read or write local project
files, create local artifacts, run validation commands, or record local evidence
ledgers when the user asks it to do so. Those actions happen in the user's local
workspace or in the agent platform selected by the user.

b3ehive does not define any bundled MCP server, hosted API, telemetry endpoint,
or external analytics service in its default Codex plugin package.

## Third-Party Platforms

Use of b3ehive with Codex, Claude Code, Cursor, Grok Build, opencode, OpenClaw,
Hermes, GitHub, or other tools is governed by the policies, settings, and data
handling practices
of those platforms. Users should review their agent platform's privacy and
workspace policies before using b3ehive on private repositories or sensitive
data.

## Sensitive Data

Users are responsible for deciding which repositories, files, prompts, commands,
and credentials are available to their agent environment. Do not expose secrets,
private customer data, or regulated data to an agent session unless your
workspace policy allows it and you understand the platform's data handling
rules.

## Changes

Privacy behavior may change if future versions add networked tools, MCP
servers, hosted services, telemetry, or integrations. Any such change should be
documented in this policy and in the release notes.
